# CAMPUSER

校园课程表 · 本地免费 · 无广告

- 数据完全保存在本机，无网络请求、无广告
- 多课表管理 / 课程多时间段 / 任意周次集合（单双周、不连续周次）
- 冲突检测、深浅主题、格子外观自定义（不透明度 / 饱和度 / 圆角 / 边距）
- 导入导出：JSON 备份与分享、CSV（Excel）、ICS 日历、文本口令 + 摄像头扫码
- 与原 WakeUp 课程表数据文件兼容，可无缝迁移

## 下载

前往 [Releases](https://github.com/shopbimaster/CampuserDownload/releases/latest) 下载最新版安装包。

### Windows

直链：**[CAMPUSER-Setup-2.1.2.exe](https://github.com/shopbimaster/CampuserDownload/releases/download/v2.1.2/CAMPUSER-Setup-2.1.2.exe)**

- 安装向导支持：自选安装位置、创建桌面快捷方式、开机自动启动
- 安装包未做代码签名，首次运行如遇 SmartScreen 提示，选择「更多信息 → 仍要运行」即可
- 纯本地应用，无自动更新；升级直接安装新版覆盖旧目录即可（数据保留），
  多个版本安装到不同目录时数据相互隔离、互不干扰

### Android

直链：**[CAMPUSER-2.1.2-android-arm64.apk](https://github.com/shopbimaster/CampuserDownload/releases/download/v2.1.2/CAMPUSER-2.1.2-android-arm64.apk)**（arm64-v8a，近年主流安卓手机均为该架构）

- 下载后直接安装；首次安装需在系统里允许「未知来源 / 安装未知应用」
- 应用声明的 INTERNET 权限系内置浏览器内核本地通信所需，应用自身不做任何网络请求
- 导出的课表文件通过系统「另存为」窗口保存到任意位置

## 更新日志

### v2.1.2（2026-10-22）

- **修复**：手机端点击已有课程打开详情后，关闭详情会在原处残留加课的粉色选中块——现在点课程只显示课程详情，关闭后不会出现加课块
- **优化**：手机端左右滑动切换周次改为「三页预渲染」——静止时同时渲染当前周与左右相邻周，滑动即时跟手（消除滑动启动瞬间的渲染卡顿），滑动中途反方向拖动不再出现未渲染的空白页穿帮；松手落定后只保留新当前页并刷新相邻页

### v2.1.1（2026-10-17）

- **修复**：Android 端导出改为系统「另存为」窗口（此前点击保存后无响应）——保存成功提示保存到了哪里，失败给出详细报错信息
- **改进**：单点加课交互细化——点已有课程仅查看详情；选中加课位置后再点其他位置先取消选中（下一次点击才重新选位）；选中块支持向上、向下双向拖动伸缩时段
- **新增**：出厂默认时间表调整为每天 12 节、每节 50 分钟（上午 8–11、下午 2–5、晚上 6–9 点整开课），学期默认 20 周
- **改进**：设置中把某节课上课时间调到晚于下课时间时，自动把下课时间对齐到上课时间（不再报错）

### v2.1.0（2026-10-17）

- **新增**：Android 端单点加课——点击课表空位出现粉色选中块，上下拖动调整节数，点按选中块即进入新建课程（时间已自动填好）
- **新增**：格子文字颜色设置（自动 / 黑色 / 白色）
- **新增**：「显示下周课程」——叠加显示下一周独有的课程（保留原色、半透明，透明度可调）
- **新增**：导入课表文件时若外观 / 上课时间设置与当前课表不同，可一键沿用当前设置
- **修复**：Android 端导入课表文件、深色模式状态栏图标颜色、Windows 桌面快捷方式图标
- **改进**：手机端左右滑动切换周次全程跟手（两页并排过渡）；上课时间新增顺序校验；去除系统点击高亮、隐藏课表滚动条；安装默认外观调整（衬底 25% / 课程块 80% / 饱和度 80% / 格子高 54 / 圆角 6 / 边距 2.5% / 表头 15px）

### v2.0.0（2026-10-13）

- **新增**：Android 版本——课程表核心功能完整可用，数据仍完全本地存储
- **修复**：Windows 安装向导中勾选「创建桌面快捷方式」后实际未创建的问题
- **焕新**：应用图标全面更换为新版矢量图标，全场景圆角呈现，小尺寸场景亦保持清晰
- **已知限制**：安卓版界面尚未针对小屏专门适配（平板 / 横屏体验较好），后续版本改进

### v1.6.0（2026-10-10）

- **新增**：导入 iCal (.ics) 日历文件——自动识别节次、周次集合与单双周，自动去重分配颜色
- **新增**：导入时询问与节次时间表匹配的日程是否存为课程格式（随「上课时间」设置统一变更）
- **新增**：外观设置「课程块饱和度」滑块（在原色基础上按比例降饱和）
- **优化**：自定义时间的课程块按节内线性插值无缝嵌入时间轴，与刻度精确对齐
- **优化**：随机配色池扩至 12 色；设置页标签不再折行
- **其他**：安装版数据目录按安装路径隔离，多版本互不干扰

### v1.5.0（2026-10-09）

- 首个 Windows 正式版：品牌定稿 CAMPUSER、统一倒角图标、NSIS 安装向导
  （自选目录 / 桌面快捷方式 / 开机自启）、多课表与任意周次、
  JSON / CSV / ICS 导出、文本口令 + 摄像头扫码
